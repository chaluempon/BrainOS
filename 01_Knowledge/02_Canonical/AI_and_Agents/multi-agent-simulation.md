# Multi-Agent Simulation

**Multi-Agent Simulation (MAS)** is a computational methodology where many autonomous agents interact within a defined environment to study emergent behavior and predict complex outcomes.

## Overview

Used in economics, epidemiology, social science, and now AI prediction. Modern LLM-based MAS (like [[MiroFish]]) gives each agent independent personality, memory, and behavioral logic — producing realistic social dynamics at scale.

## Key Points

- **Agents:** Each is autonomous, with own state and goals
- **Environment:** Shared space where interactions occur
- **Emergence:** Collective behavior not programmed explicitly
- **Scale:** Thousands to millions of agents possible
- **Temporal dynamics:** Agents evolve, remember, adapt

## MiroFish Implementation

- **Dual-platform parallel simulation** for efficiency
- **Agent memory** via [[Zep Cloud]]
- **Persona generation** automatic from seed data
- **Dynamic temporal memory updates** during simulation
- Post-simulation: **chat with any agent** or with ReportAgent

## Tools & Frameworks

- [[OASIS Framework]] (CAMEL-AI) — used by MiroFish
- Mesa (Python) — general-purpose MAS
- NetLogo — agent-based modeling classic
