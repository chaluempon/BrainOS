## Summary

MiroFish is an open-source next-generation AI prediction engine powered by multi-agent technology. It constructs high-fidelity parallel digital worlds from real-world seed information, where thousands of intelligent agents with personalities, memory, and behavioral logic interact and evolve socially. Users can inject variables from a "God's-eye view" to simulate future trajectories — essentially rehearsing the future in a digital sandbox before making decisions.

The project is incubated by Shanda Group and powered by the OASIS simulation framework from CAMEL-AI team.

## Key Takeaways

- **Purpose:** Predict anything (public opinion, finance, politics, creative scenarios) via multi-agent simulation
- **Input:** Seed materials (reports, news, stories) + natural language prediction requirements
- **Output:** Detailed prediction report + interactive high-fidelity digital world
- **Two Use Cases:** Macro (decision-maker rehearsal lab) and Micro (creative sandbox for individuals)
- **Tech Stack:** Node.js 18+, Python 3.11-3.12, uv package manager, Docker support
- **LLM:** Uses OpenAI-compatible APIs (recommends Alibaba Qwen-plus)
- **Memory:** Uses Zep Cloud for agent memory

## Workflow Steps (from source)

1. **Graph Building**: Seed extraction & memory injection & GraphRAG construction
2. **Environment Setup**: Entity relationship extraction & persona generation & agent configuration
3. **Simulation**: Dual-platform parallel simulation & dynamic temporal memory updates
4. **Report Generation**: ReportAgent with rich toolset for deep interaction
5. **Deep Interaction**: Chat with any agent in simulated world
