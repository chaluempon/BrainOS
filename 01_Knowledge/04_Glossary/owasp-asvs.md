# OWASP ASVS

OWASP Application Security Verification Standard is a security requirements and verification standard for web applications and web services.

## Definition

ASVS gives teams a structured list of security controls to design, build, and test against. It is useful as a baseline for authentication, session management, access control, validation, cryptography, error handling, API security, and configuration.

## When To Use

- Web applications.
- REST, GraphQL, or RPC APIs.
- Internal admin systems with sensitive data.
- Any project that needs repeatable application security requirements.

## How AI Agents Should Use It

- Treat ASVS as the security baseline when building web/API projects.
- Turn relevant ASVS sections into acceptance criteria.
- Mention any skipped security requirement as an explicit risk.
