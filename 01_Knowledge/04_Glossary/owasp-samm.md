# OWASP SAMM

OWASP Software Assurance Maturity Model is a framework for improving secure software development across the full software lifecycle.

## Definition

SAMM helps teams assess and improve security practices across governance, design, implementation, verification, and operations. It is technology-agnostic and works as a roadmap rather than a single fixed checklist.

## When To Use

- Building a long-term engineering standard.
- Auditing how a team designs, builds, verifies, and operates software.
- Creating a security improvement roadmap.

## How AI Agents Should Use It

- Use SAMM to think beyond code-level vulnerabilities.
- Add security work into design, implementation, verification, and operations.
- Make security improvement measurable and repeatable.
