# Hermes Agent

Hermes Agent คือ AI Agent ที่คลิปนี้นำมาใช้ร่วมกับ Obsidian และ Codex CLI เพื่อจัดระเบียบและบันทึกความรู้แบบอัตโนมัติ

## บริบทใน vault

- เป็นส่วนหนึ่งของ workflow สำหรับเปลี่ยนโน้ตที่กระจัดกระจายให้เป็น knowledge base ที่ค้นหาและเชื่อมโยงได้
- คลิปสาธิตการเริ่มต้นใช้งาน Hermes Agent Desktop และการให้ Agent บันทึกข้อมูลใน Obsidian
- แนวทางดังกล่าวควรใช้กับข้อมูลที่ได้รับอนุญาตเท่านั้น และไม่ควรส่ง secrets หรือข้อมูลภายในให้ Agent ประมวลผล
