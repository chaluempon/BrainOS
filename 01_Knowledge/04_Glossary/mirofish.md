# MiroFish

**MiroFish** is a next-generation open-source AI prediction engine that uses multi-agent technology to construct high-fidelity parallel digital worlds for simulating and predicting real-world events.

## Definition

MiroFish creates "swarm intelligence mirrors that map reality." It extracts seed information from the real world (news, policies, financial signals) and automatically generates thousands of intelligent agents with independent personalities, long-term memory, and behavioral logic. These agents freely interact and socially evolve in a simulated digital sandbox, allowing users to predict future trajectories by adjusting variables from a "God's-eye view."

## Key Facts

- **Type:** Open-source AI prediction engine

- **Simulation scale:** Thousands of agents per simulation

## Use Cases

### Macro Level
- **Rehearsal laboratory** for decision-makers
- Zero-risk testing of policies and PR strategies
- Financial & political event prediction

### Micro Level
- **Creative sandbox** for individuals
- Deducing novel/fiction endings (e.g. Dream of the Red Chamber)
- "What if" scenario exploration

## How It Works

Follows a 5-step [[MiroFish Workflow]]:
1. Graph Building (seed + [[GraphRAG]])
2. Environment Setup (entity extraction + persona generation)
3. Simulation (dual-platform parallel)
4. Report Generation (ReportAgent)
5. Deep Interaction (chat with agents)

## Technology Stack
