# OASIS Framework

**OASIS** (Open Agent Social Interaction Simulations) is an open-source multi-agent simulation framework created by the [[CAMEL-AI]] team. It powers the simulation engine of [[MiroFish]].

## Definition

A framework for running large-scale social interaction simulations with LLM-powered agents. OASIS provides the infrastructure for agents to interact, communicate, form memories, and exhibit emergent collective behaviors.

## Key Facts

- **Created by:** [[CAMEL-AI]] team
- **Repository:** https://github.com/camel-ai/oasis
- **License:** Open source
- **Role:** Simulation engine underlying [[MiroFish]]

## Relationship to MiroFish

MiroFish explicitly credits OASIS as its simulation backbone:
> "MiroFish's simulation engine is powered by OASIS (Open Agent Social Interaction Simulations), We sincerely thank the CAMEL-AI team for their open-source contributions!"
