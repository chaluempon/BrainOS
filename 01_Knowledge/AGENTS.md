# Knowledge Library Agent Contract

1. Read `../GLOBAL_RULES.md` first.
2. Read `00_HOME.md` and the relevant file under `01_Indexes` before detailed notes.
3. Retrieve only relevant canonical notes; do not load the entire vault without need.
4. Treat `approved` and `published` notes as the primary factual basis. Treat `draft` and `under_review` as supporting context.
5. Cite both canonical note and source record for material factual claims.
6. Do not edit knowledge unless authorized as Knowledge Curator or Librarian.
7. Do not send `confidential` or `restricted` notes to external AI, RAG, or connectors without authorization.
8. Task memory and audit records are not canonical knowledge.
