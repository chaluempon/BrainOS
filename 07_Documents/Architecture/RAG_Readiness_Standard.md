# RAG Readiness Standard

Phase 1 creates no vector database.

Eligible notes must have a focused subject, summary, stable identity, status, access level, sources, clear headings, and deprecation/version metadata where applicable. Only statuses allowed by the future Knowledge-to-Platform contract may be indexed.

Retrieval must filter access before results leave the storage boundary. Each chunk must trace back to a canonical note and source record. Index builds record a knowledge release identifier and are rebuildable from BrainOS.
