# Knowledge Governance

**Status:** Active foundation policy
**Owner:** BrainOS Owner

Every canonical note has an accountable owner, sources, lifecycle status, access level, and review date when material. AI-generated and migrated content begins as `draft`. Security policy, architecture standards, production instructions, legal/compliance, personal data, financial data, and access control require human review.

Lifecycle: inbox → draft → under_review → approved → published → needs_update → deprecated → archived. Rejected content remains traceable when necessary.

Confidential and restricted content cannot be sent to external AI/RAG/connectors without authorization. Changes remain auditable through Git, migration manifests, decision records, and review metadata.
