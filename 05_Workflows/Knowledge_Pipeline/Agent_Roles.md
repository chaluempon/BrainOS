# Knowledge Pipeline Agent Roles

- Researcher: gathers relevant sources and context.
- Fact Checker: compares claims and records uncertainty.
- Curator: extracts and structures knowledge.
- Documentation Writer: applies Markdown and metadata standards.
- Reviewer: checks accuracy, completeness, and duplication.
- Indexer: updates indexes and relationships.
- Librarian: controls canonical placement, naming, and lifecycle.
- Security Reviewer: checks secrets, PII, internal data, and access classification.

Agents cannot self-approve sensitive or material knowledge.
