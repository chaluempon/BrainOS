# Knowledge Review Checklist

- [ ] Canonical note is unique.
- [ ] Material claims link to source records.
- [ ] Metadata has title, category/domain, status, access level, dates, and tags.
- [ ] No secrets, credentials, PII, internal network details, or restricted data are exposed.
- [ ] UTF-8 and Thai text are intact.
- [ ] Wikilinks resolve and aliases remain usable.
- [ ] Attachments and local references exist.
- [ ] Status reflects actual human review.
- [ ] Deprecation and successor links are explicit.
- [ ] Indexes are updated.
