# BKOS System Layer

`00_System` contains governance links, standards, templates, agent profiles, and configuration guidance for BrainOS Knowledge Operating System (BKOS).

- Canonical global rules remain at [`../GLOBAL_RULES.md`](../GLOBAL_RULES.md).
- Knowledge content belongs in `01_Knowledge`.
- Runtime configuration and secrets do not belong here.
- Standards define minimum requirements; templates provide reusable starting points.
