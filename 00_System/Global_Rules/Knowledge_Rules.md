# Knowledge Rules

**Status:** Active standard
**Owner:** BrainOS Owner

1. One subject has one canonical note.
2. Every material claim must be traceable to a source record.
3. AI-generated or migrated content defaults to `draft`; it is never automatically approved.
4. Raw inputs stay in `09_Inbox`; processed originals stay in `10_Archive`.
5. Derived RAG indexes are rebuildable runtime data and are not canonical knowledge.
6. Runtime task memory is not promoted to canonical knowledge without review.
7. Confidentiality classification is enforced before retrieval or external processing.
8. Deprecated notes identify their successor and retain historical traceability.
