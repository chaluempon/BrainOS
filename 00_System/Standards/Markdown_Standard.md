# Markdown Standard

**Status:** Active standard

- Use one H1 matching the note title.
- Begin canonical notes with a short human- and AI-readable summary.
- Use descriptive H2/H3 headings and fenced code blocks with a language identifier.
- Use Obsidian `[[wikilinks]]` for internal knowledge links and standard Markdown links for external sources.
- Do not create empty sections merely to satisfy a template.
- Preserve technical names, commands, CVEs, and product names verbatim.
- UTF-8 is required; Thai content must round-trip without replacement characters.
- Material factual claims cite a source record under `01_Knowledge/03_Sources`.
